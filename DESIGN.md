# Field Notebook

The approved direction is an author's working notebook, not a product landing
page. The same light-only shell applies to About, research explainers, blog
indexes and posts, projects and project notes, publications, news, and Now.

Use the warm-neutral Clawpilot tokens in `assets/css/notebook.css`, with rose
reserved for annotations, active navigation, and the paper-cut illustration.
Use Segoe UI/Aptos/Calibri and the native sans-serif fallback stack; monospace
is for code only. Never consult the operating-system theme or restore an old
dark-mode preference.

Desktop has a sticky author margin beside an open reading spread. On mobile,
the margin becomes a compact wrapping navigation above the content. Entries
are divided by rules rather than boxed into repeated cards. Body copy stays
near 70 characters wide; project images and code blocks stay responsive.

Preserve all existing blog and project URLs. Publications are grouped from the
bibliography dynamically, so a new year cannot disappear behind a fixed list.
Google Scholar is the live citation record; do not embed changing citation
counts. News is date-sorted and linked to supporting sources. Draft videos
are identified as in preparation, never as published episodes.

The contact address is plain obfuscated text, never a mailto link or a hidden
unobfuscated attribute.
